## Security

Security is taken seriously here:

- Every push and pull request is scanned by a **Malware Guard** workflow that flags the
  persistence patterns and obfuscated code seen in a 2026-09 incident.
- Never push directly to `main` — changes go through pull requests.
- Report vulnerabilities **privately** via the `SECURITY.md` files in each repository; do
  not open a public issue.
